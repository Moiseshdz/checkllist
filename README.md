# Herramientas Operativas Web

Colección de aplicaciones web desarrolladas para **digitalizar procesos operativos, reducir tareas manuales y mejorar el seguimiento de información**.

Este repositorio reúne prototipos y herramientas funcionales creadas con enfoque en interfaces rápidas, uso práctico y automatización de procesos.

## Proyectos incluidos

### Checklist de monitoreo
Herramienta para registrar revisiones, fallas y resultados de turno de forma estructurada.

### FATIGA — Control operativo
Sistema para seguimiento de unidades, incidencias, estados operativos y códigos de cierre.

### Sistema de notas
Aplicación para organizar y estructurar notas, mejorar la captura de información y mantener los registros relacionados.

## Tecnologías

- HTML5
- CSS3
- JavaScript
- JSON
- LocalStorage
- Interfaces web responsivas

## Objetivos técnicos

- Automatizar tareas repetitivas
- Centralizar información operativa
- Reducir errores de captura
- Facilitar búsquedas y seguimiento
- Crear herramientas ejecutables directamente en navegador
